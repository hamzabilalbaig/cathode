What support covers

  • Covered: bugs in the theme, questions about settings and sections, and help understanding how a feature works.
  • Not covered: custom code, app integrations, design work, and changes to a theme whose code has been edited. We are happy to quote for these separately.
  • Critical bugs are fixed immediately.

Before you write

  • Check the documentation — the FAQ covers the most common setup questions.
  • If you have edited theme code, duplicate your theme before making further changes.
  • Tell us your store URL and which preset you are using.
